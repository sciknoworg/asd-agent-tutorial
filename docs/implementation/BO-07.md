# BO-07 Implementation Note

Task ID: BO-07
Title: Complete Stage 2 benchmark and analysis
Branch: `main`

## Scope

BO-07 adds a Stage 2 comparison framework for:

- random search;
- grid search;
- deterministic rule-based search;
- constrained multi-objective BO.

The benchmark is opt-in and does not change legacy benchmark behavior, simulator
semantics, or LLM workflows.

## Benchmark Design

`Stage2BenchmarkProfile` records scenarios, methods, repetitions, fixed budgets,
matched initial design size, seeds, grid settings, cycle candidates, and MOBO
settings. Smoke and pilot profiles are configured in YAML.

All methods use the Stage 2 decision variables from BO-05:

- precursor dose;
- temperature;
- integer cycle count.

Coreactant and inhibitor doses remain fixed by the Stage 2 scenario configuration.
The deterministic rule-based method adapts the existing rule-based candidate plan to
these three variables.

## Endpoints

Primary endpoint:

- area under the feasible observed hypervolume trajectory under a fixed experiment
  budget.

Secondary endpoints:

- final feasible success;
- experiments to first feasible condition;
- final hypervolume;
- hypervolume regret against the evaluation-only oracle hypervolume;
- constraint-violation count;
- boundary-proposal count;
- failure category.

The oracle is used only for evaluation metrics and analysis source data. It is not
provided to optimizers.

## Analysis Outputs

`generate_stage2_analysis_outputs` writes CSV/PNG pairs for:

- search trajectories;
- observed and oracle Pareto fronts;
- hypervolume by iteration;
- hypervolume AUC;
- final regret;
- experiments to first feasible point;
- constraint-violation counts;
- robustness by scenario;
- failure taxonomy.

Every figure has a CSV source file beside it.
