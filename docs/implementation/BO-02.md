# BO-02 Implementation Note

Task ID: BO-02
Title: Add Stage 1 saturation-process families and evaluation oracle
Branch: `main`

## Scope

BO-02 adds one-dimensional virtual process families for studying active learning of
ALD-like precursor saturation. It does not add Gaussian-process fitting, acquisition
functions, adaptive experiment selection, Stage 2 optimization, or LLM integration.

## Process Families

Configured Stage 1 scenarios:

- `bo_stage1_fast_mono`: fast mono-exponential saturation.
- `bo_stage1_slow_mono`: slow mono-exponential saturation.
- `bo_stage1_soft_biexponential`: soft bi-exponential saturation.
- `bo_stage1_noisy`: noisy mono-exponential saturation.
- `bo_stage1_weak_nonselflimited`: weakly non-self-limited growth with a small linear
  tail.
- `bo_stage1_misspecified`: saturating curve intentionally misspecified for a simple
  mono-exponential assumption.

The finite saturating families use variants of:

```text
g(t) = g_inf * (1 - exp(-k * t))
```

The soft process combines fast and slow exponential components. The non-self-limited
process adds a small linear contribution and is classified as lacking a meaningful
saturation threshold.

## Modes

Stage 1 supports two explicit modes:

- `known_target`: the optimizer-facing view includes `target_growth`.
- `inferred_asymptote`: the optimizer-facing view omits `target_growth`; the asymptote
  is hidden and used only for evaluation.

`Stage1Objective` validation rejects mixed-mode configurations.

## Oracle Boundary

The evaluation-only oracle can report:

- true finite saturation value when one exists;
- analytical t95 for mono-exponential families;
- numerical t95 for monotonic finite-asymptote families;
- whether a meaningful saturation threshold exists;
- dense true evaluation curves.

Optimizer-facing APIs do not expose hidden process family, rate constants, true t95,
true asymptote, or scenario labels. Tests assert this boundary.

## Metrics Prepared

`evaluate_recommendation` calculates:

- estimated t95;
- true t95 for evaluation only;
- absolute t95 error;
- relative t95 error;
- growth fraction at the recommendation;
- dose overshoot;
- cumulative dose;
- cumulative simulated process time;
- false saturation declaration.

## Remaining Limitations

- Stage 1 currently has a simple dose-only record type rather than a full BO runner.
- Candidate selection is intentionally absent.
- The misspecified process is a tutorial stress test, not a claim about real ALD
  chemistry.
- The non-self-limited classification is intentionally conservative: it treats a
  continuing linear tail as no meaningful saturation threshold.
