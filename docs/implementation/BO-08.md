# BO-08 Implementation Note

Task ID: BO-08
Title: Integrate BO into the hybrid LLM scientific agent
Branch: `main`

## Scope

BO-08 adds an opt-in hybrid LLM-BO orchestrator for Stage 2 ASD optimization. The
existing LLM-only agent remains available as a research comparator and is not
modified.

## Responsibilities

The hybrid layer separates responsibilities:

- LLM: inspect history, request BO candidates, review candidate IDs, explain concise
  decisions, propose validated soft-bound changes, query local/mock literature, and
  decide whether to continue or stop.
- BO: propose numerical Stage 2 candidates with uncertainty and feasibility summaries.
- Backend: execute only validated candidate IDs in the virtual laboratory.

## State Machine

Implemented states:

- `INITIALIZE`
- `INSPECT_HISTORY`
- `REQUEST_BO_CANDIDATES`
- `REVIEW_CANDIDATES`
- `EXECUTE_CANDIDATE`
- `OBSERVE`
- `CONTINUE`
- `CHANGE_SOFT_BOUNDS`
- `FINISH`
- `DECLARE_NO_WINDOW`

The event log records concise rationale strings only. Hidden chain-of-thought is not
requested or stored.

## Strict Tools

Implemented strict tools:

- `inspect_experiment_history`
- `run_bayesian_optimizer`
- `run_virtual_experiment`
- `change_search_bounds`
- `finish_optimization`
- `declare_no_selective_window`
- `query_literature`

`run_virtual_experiment` accepts `candidate_id` only. It rejects arbitrary numerical
reactor conditions.

## Literature Providers

Implemented:

- `NullLiteratureProvider`
- `MockLiteratureProvider`
- `LocalLiteratureProvider`

No mandatory live web retrieval is added.

## Modes

Implemented modes:

- `bo_only`
- `llm_only_legacy`
- `hybrid_advisory`
- `hybrid_intervention`
- `hybrid_explanation_only`
- `rule_based_bo`

`llm_only_legacy` is preserved as a separate comparator-style path and does not replace
the existing `LLMOptimizationAgent`.

## Remaining Limitations

- The hybrid orchestrator uses fake/local providers by default; live OpenAI and live
  literature retrieval are intentionally out of scope.
- The BO proposals remain tutorial-scale and CPU-oriented.
- Python 3.14 compatibility remains unverified locally; verification uses bundled
  Python 3.12.13.
