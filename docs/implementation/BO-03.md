# BO-03 Implementation Note

Task ID: BO-03
Title: Implement Stage 1 grid search and generic-GP active learning
Branch: `main`

## Scope

BO-03 adds two Stage 1 comparison methods:

- a fixed, predetermined dose grid;
- a one-dimensional generic Gaussian-process active learner using BoTorch and
  GPyTorch.

It does not add a physics-informed GP, Stage 2 constrained optimization, or any LLM
integration.

## Implemented Architecture

New modules:

- `src/asd_agent/bo/gp.py`: float64 generic GP fitting and posterior prediction.
- `src/asd_agent/bo/acquisition.py`: threshold-oriented candidate selection.
- `src/asd_agent/bo/optimizers.py`: fixed-grid optimizer, generic-GP optimizer,
  Stage 1 run settings, run results, and comparison runner.
- `scripts/compare_stage1_methods.py`: small BO-03 smoke comparison script.

The generic GP uses:

- BoTorch `SingleTaskGP`;
- normalized one-dimensional dose inputs;
- standardized outputs;
- GPyTorch Matérn 5/2 kernel inside a scale kernel;
- inferred-noise and known-noise modes;
- deterministic torch seeds;
- fit retries with warning capture.

## Threshold Acquisition Rule

The acquisition rule evaluates posterior probability on a finite dose grid:

```text
p(t) = P(g(t) >= y_target)
```

The operational rule is:

1. Estimate `y_target` from optimizer-visible information.
2. Choose the smallest untested dose whose `p(t)` exceeds the configured probability
   threshold.
3. If no dose satisfies that threshold, choose the untested point maximizing:

```text
sigma(t) * exp(-abs(mu(t) - y_target) / bandwidth)
```

This samples where the model is uncertain near the saturation threshold. Duplicate
doses are filtered before selection. If no untested candidate remains, the optimizer
returns an explicit failure.

## Recommendation Rule

The final recommendation is never an untested model optimum. A successful run reports
the smallest tested Stage 1 ledger row whose observed growth reaches the current
threshold estimate, and stores its `recommended_experiment_id`.

## Remaining Limitations

- The generic GP is intentionally generic and does not encode saturation physics.
- The inferred-asymptote threshold estimate is based on optimizer-visible observations
  and posterior means, so it is a teaching heuristic rather than a robust scientific
  estimator.
- BO-03 does not add long-form benchmarking, statistical repetitions, or plots.
- Python 3.14 compatibility remains unverified in this workspace; verification used
  the bundled Python 3.12.13 runtime.
