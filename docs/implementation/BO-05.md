# BO-05 Implementation Note

Task ID: BO-05
Title: Define Stage 2 constrained multi-objective ASD problem
Branch: `main`

## Scope

BO-05 prepares the existing two-surface ASD simulator for constrained
multi-objective optimization. It defines the Stage 2 problem, scenarios, oracle, and
simulator-only plots. It does not implement a MOBO acquisition function.

## Decision Variables

Stage 2 exposes exactly three optimizer-facing variables:

- `precursor_dose_s`: continuous;
- `temperature_c`: continuous;
- `cycle_count`: integer.

Coreactant dose and inhibitor dose are fixed scenario parameters.

## Outcomes, Objectives, and Constraints

Measured outcomes:

- GA thickness;
- NGA thickness;
- selectivity;
- total simulated process time.

Objectives:

- maximize useful GA growth;
- minimize NGA growth;
- minimize process time.

Selectivity is not optimized alone. It remains a feasibility constraint.

Constraints are configured in YAML:

- minimum GA thickness;
- maximum NGA thickness;
- minimum selectivity.

Hard safety bounds are immutable Pydantic fields covering precursor dose,
temperature, integer cycle count, and optional total permitted process time.

## Scenarios

The original ASD scenario YAML files are preserved. BO-05 adds Stage 2 YAML files for:

- `bo_stage2_inherent_selectivity`
- `bo_stage2_inhibitor_selectivity`
- `bo_stage2_impossible_selectivity`
- `bo_stage2_narrow_selective_window`
- `bo_stage2_noisy_measurements`
- `bo_stage2_boundary_optimum`
- `bo_stage2_soft_selectivity_breakdown`
- `bo_stage2_model_misspecification`

Scenario intent, visible bounds, hidden process-parameter summaries, noise, feasibility
thresholds, expected feasibility, and difficulty are documented in
`docs/stage2_scenarios.md` and in each YAML metadata block.

## Evaluation Oracle

`Stage2EvaluationOracle` performs evaluation-only mixed-variable enumeration. It
reports:

- feasible-region map points;
- approximate Pareto front;
- approximate normalized hypervolume;
- whether a selective window exists.

Oracle values are not included in `Stage2Config.optimizer_view()`.
