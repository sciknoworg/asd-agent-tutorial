## Architecture

The research harness converts Stage 1 saturation, Stage 2 constrained ASD, and
hybrid LLM-BO runs into a shared `ResearchResultRow` schema. Each row records the
profile ID, research question, study area, pair ID, repetition, scenario, method,
named seeds, status, success flag, primary metric, failure category, and a scalar
metrics payload.

`paired_seed_schedule` creates deterministic named seeds for:

- simulator;
- measurement noise;
- initialization;
- BO;
- LLM.

Methods compared within a pair share scenario/repetition identity and matched
noise streams. The harness calls existing simulator, benchmark, and hybrid-agent
entry points rather than duplicating virtual laboratory logic.

## Profiles

- `bo_research_smoke`: 2 repetitions for fast local checks.
- `bo_research_pilot`: 20 repetitions for pilot studies.
- `bo_research_paper_non_llm`: 100 paired repetitions for Stage 1 and Stage 2.
- `bo_research_paper_llm`: 30 paired repetitions for hybrid-agent studies.

The paper profiles are configuration only in BO-09.

## Statistics

The statistics module implements:

- paired treatment-minus-control effect estimates;
- paired bootstrap confidence intervals;
- exact McNemar paired-success comparisons;
- Wilcoxon signed-rank secondary tests with a sign-test fallback;
- Holm correction within research-question families;
- cumulative success curves;
- failure-category summaries.

Outputs are written as CSV, JSON, Markdown, and LaTeX tables.
