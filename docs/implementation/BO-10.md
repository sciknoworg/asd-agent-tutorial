## Architecture

The completed BO stack is layered as:

1. Legacy ASD simulator, objective checks, random/grid baselines, rule-based agent,
   and optional Responses API LLM agent.
2. BO shared records and virtual backend wrappers.
3. Stage 1 saturation-process families, oracle, grid search, generic GP, and
   physics-informed GP.
4. Stage 2 constrained ASD problem, oracle, constrained MOBO, and benchmark analysis.
5. Hybrid LLM-BO state machine using BO for numerical candidates and strict tools for
   LLM orchestration.
6. Paired research harness and statistical reporting.
7. Manual laboratory handoff that exports validated plans and imports human-completed
   measurements as Stage 2 observations.

`ManualLabBackend` receives candidates, validates immutable Stage 2 hard bounds,
exports pending plans, validates nanometer measurement units and required metadata,
rejects failed quality-control rows, updates the Stage 2 observation ledger, and
returns observations that can seed continued BO.

## Limitations

- The simulator is educational and non-predictive.
- Manual lab safety notes are not a substitute for local laboratory review.
- The handoff backend does not perform unit conversion beyond requiring nanometers.
- Failed quality-control rows are rejected rather than retained in the optimizer
  ledger.
- Smoke results are software checks, not research conclusions.
