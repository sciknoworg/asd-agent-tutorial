# Prompts Directory

This directory is reserved for prompt templates and prompt documentation used by
future LLM-assisted BO stages.

## Rules

- Do not store API keys, credentials, `.env` contents, or private user data.
- Do not store hidden chain-of-thought.
- Store only concise rationales and explicit prompt templates.
- Keep prompt templates versioned and tied to the task or stage that introduced them.
- Prefer deterministic no-API tests for prompt-schema behavior.

## Suggested Naming

- `bo-08-hybrid-system.md`
- `bo-08-hybrid-tool-contract.md`
- `bo-09-study-instructions.md`
